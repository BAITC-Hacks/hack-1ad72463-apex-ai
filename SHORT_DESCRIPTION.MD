# Apex Match

**Apex Match** — веб-сервис команды **Apex-AI** для быстрого и прозрачного подбора подрядчиков на мероприятия. Организатор указывает город, категорию услуги, дату, формат события, бюджет, язык и длительность работы, а система возвращает до трёх подходящих исполнителей со стартовой ценой и объяснением выбора.

Сервис проверяет требования по формату, бюджету, языку, продолжительности и доступности на выбранную дату. Подходящие профили сортируются по цене, а для неподходящих кандидатов система показывает причины исключения. Это делает результат воспроизводимым и понятным пользователю.

В базовом каталоге — **66 профилей в 17 категориях**. Данные хранятся в PostgreSQL и управляются через отдельную защищённую админ-панель с поиском, редактированием, CSV-импортом и экспортом, предварительной проверкой изменений и журналом действий.

**Стек:** React 19, TypeScript, Vite, Go, PostgreSQL, Docker, Nginx.
