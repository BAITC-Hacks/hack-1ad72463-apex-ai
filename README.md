# Apex Match

Apex Match — сервис подбора до трёх event-подрядчиков из заданного каталога. Продукт должен строго учитывать город, дату, формат, категорию, бюджет и опциональные ограничения, а каждую рекомендацию объяснять проверяемыми фактами.

## Статус

Сейчас в репозитории только план реализации. Приложение, команды запуска, тесты и deployed URL ещё не созданы. Наша зона работы — React/TypeScript/Vite frontend; Go backend разрабатывается отдельно, а его фактические endpoint пока не подтверждены.

Исходный DOCX кейса и CSV-каталог были проверены в предоставленном рабочем каталоге, но исходные данные в Git не добавлены. До начала реализации команде нужно подтвердить, можно ли коммитить каталог, или согласовать воспроизводимый внешний путь к нему.
